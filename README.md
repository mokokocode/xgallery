# XGallery

Fast Wi-Fi gallery and photo transfer for older Fujifilm X cameras (built for the X-Pro2).

Current version: step 1, connection test. It connects over Wi-Fi, reads the photo list and the first
10 thumbnails, and shows a log you can share.

The Fuji protocol details come from Daniel Cook's MIT-licensed [libfuji](https://github.com/petabyt/libfuji).

## Getting the APK
Every push builds a debug APK with GitHub Actions: open the Actions tab, click the latest run,
and download `XGallery-apk` under Artifacts.
